# career-ops — Murad’s customized edition

My customized job-search pipeline with local workflow commands and remote-region filtering.

Maintained by [Murad](https://github.com/muradiodev).

## This edition

- My legacy remote-region location filter in `scan.mjs`.
- Additional OpenCode command entrypoints for application workflows.
- Upstream tools for job discovery, evaluation, CV generation, and pipeline tracking.

## Setup

See the [upstream setup and usage documentation](UPSTREAM_README.md). Create your own local profile from the supplied templates.

This is a public source snapshot. Credentials, private application records, and local runtime data are excluded. Fill in your own contact details and configuration before use.
